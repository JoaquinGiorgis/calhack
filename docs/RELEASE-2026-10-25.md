# FortWatch: direct iPhone listening, 521 sounds and Orbit displays

This release adds a native iPhone app that recognizes sounds locally and sends
alerts directly to the ESP32-S3 wristband over Bluetooth LE. The Mac is used for
development and installation; it is not required while listening. The original
Mac listener remains available as a fallback.

## What changed

- **Recognition:** bundled Google YAMNet runs through Core ML. All 521 class names
  have stable IDs, searchable library entries and wristband titles. Silence is
  listed but does not automatically alert. A dominant class is selected from
  each window; related parent labels are suppressed when a specific child wins.
- **Direction:** the iPhone's spatial audio feeds a phone-relative direction
  estimator and front calibration. Both displays show only usable, fresh angles.
  Calibration failures, unknown directions and expired readings are explicit.
  Recognition can continue when direction is unavailable.
- **Bluetooth:** event messages trigger alerts, display-only updates refresh the
  screen without restarting vibration, and manual pattern tests are marked TEST.
  Tests and display updates do not create dashboard events. Existing ten-alert
  messages remain compatible.
- **Vibration:** distinct learned alert patterns and shared family patterns cover
  the catalog. Related sounds share rhythms; there are not 521 unique patterns.
  A single motor signals sound type, while direction is communicated on screen.
- **Design:** native iPhone and 320×240 wristband alerts now share the website's
  graphite surfaces, white Gabarito/Atkinson type and lime accent. Orbit emphasizes
  the sound name, a bearing crescent around a phone reference, the direction label
  and the vibration rhythm. All product text is English. Large text, long names
  and uncertain/recent/test states have dedicated rendering checks.
- **Dashboard:** the existing private configuration is preserved. A compatibility
  adapter sends only the 36 exact legacy source classes using existing event names.
  The remaining 485 classes stay on phone/wristband until the dashboard schema is
  expanded. This repository does not contain that remote dashboard's source.

## What was verified

| Converted model | 238 reference windows preserved original top labels; synthetic score/resampling tests also passed on the connected iPhone |
| Firmware contracts | All 521 catalog IDs plus ten legacy IDs checked for exact rhythm compatibility; display lifecycle and analytics isolation passed |
| Firmware rendering | 1,956 frames under ASan/UBSan; complete names fit for all 521 classes; 361 software bearing inputs checked |
| Builds | Simulator, signed iPhone and ESP32-S3 firmware builds passed |
| Installation | Revision `1e782dc` installed on both devices: iPhone launch and running process confirmed; ESP32 app0 hash verified and BLE advertisement detected after reboot |

The firmware update wrote only app0 after matching the partition table. It did
not erase NVS or change credentials. Signing-team preferences and private Wi-Fi/
dashboard credentials remain local. No new physical microphone, motor or dashboard
upload test is implied by successful installation.

## Try it

1. Power the wristband, open FortWatch and tap **Connect**. Stop any Mac receiver
   that may already be using the wristband's BLE connection.
2. Open **Sound library** and use **Test** to learn a rhythm, or use
   **Test vibration** for KNOCK's two short pulses.
3. Tap **Start listening**. For direction, keep the iPhone upright and fixed,
   then use **Calibrate front** with a steady sound in front. Check left, front
   and right against the real source; do not infer accuracy from a moving arc.

## Still pending

Physical calibration/sign/angle accuracy remains unresolved. The latest model
needs live microphone and full phone-to-wristband screen/motor validation.
Recorded replay results include misclassifications; the catalog size and model
conversion checks are not a claim of reliable recognition of every sound.

The app must remain open. Background/pocket listening, the spoken “Fortnite”
command, independent localization of simultaneous sources and the expanded
dashboard vocabulary are not implemented. Focus is an alternative design mockup;
Orbit is the implemented display direction.
